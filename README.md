# Kit OS do Cara da IA

Um segundo cérebro em arquivos markdown, operado pelo Claude, com um painel visual no seu computador.

## Já tem o OS instalado?
Abra o Claude na pasta do seu segundo cérebro e diga:

> Confere se meu OS precisa atualizar: <cole aqui o link deste repositório>

Ele vê a sua versão, compara com a mais nova e, se houver novidade, explica o que muda, faz backup e
só atualiza com o seu "pode". O passo a passo que ele segue está em [ATUALIZAR.md](ATUALIZAR.md).

## Vai instalar pela primeira vez?
Comece pelo [LEIA-PRIMEIRO.md](LEIA-PRIMEIRO.md).

## Versões
A versão deste kit está em [VERSAO.txt](VERSAO.txt) e o que mudou em cada uma, no [CHANGELOG.md](CHANGELOG.md).
